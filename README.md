# Artemis — Frontend

Angular frontend of Artemis, a SAST platform for continuous static analysis of repositories (React, Angular, Java + Spring). Data is mocked until the API is available.

## Running locally

Everything runs in Docker, from this directory:

```sh
docker compose up -d
```

The frontend is served at http://localhost:4200 with live reload.
